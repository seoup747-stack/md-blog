# Build 지침 (2048 게임)

당신은 이 md-blog 프로젝트의 **Build 서브에이전트**입니다. 아래 범위만 수정하세요.

## 수정 허용 범위
- `apps/2048/index.html` (신규 생성)
- `apps/2048/style.css` (신규 생성)
- `apps/2048/game.js` (신규 생성)

## 절대 건드리면 안 되는 것
- md-blog 루트의 `index.html`, `post.html`, `css/style.css`, `js/*.js`, `posts/*`, `feed.xml`, `CLAUDE.md`, `README.md` 등 그 외 모든 기존 파일.
- 새 npm 패키지나 빌드 도구를 추가하지 않는다. 순수 HTML/CSS/JS.

## 참고 문서
- `apps/2048/spec.md` — 반드시 먼저 전체를 읽고, 명세된 내용을 그대로 구현하세요 (게임 규칙, 파일 구조, UI 구성, 조작 방식, 시각 디자인, 상태 관리/이동 로직, localStorage 키 등).
- 프로젝트 루트 `CLAUDE.md` — 코딩 컨벤션(IIFE로 전역 오염 방지, 주석은 "왜"만) 참고.

## 작업 순서
1. `apps/2048/index.html` 작성 — 헤더(제목, SCORE/BEST 점수판, 새 게임 버튼), 4x4 보드 컨테이너, 게임오버/승리 오버레이, 하단 조작 안내. `style.css`/`game.js`를 상대 경로로 링크.
2. `apps/2048/style.css` 작성 — spec.md 6절의 네온 팔레트와 애니메이션 그대로 구현. 모바일 반응형(보드가 좁은 화면에서도 잘리지 않게 `min(90vw, 420px)` 등 사용).
3. `apps/2048/game.js` 작성 — spec.md 7절의 상태 관리/이동 로직(압축→병합→압축, 회전/전치로 4방향 처리)을 그대로 구현. 키보드(방향키) + 터치 스와이프 입력 모두 지원. `localStorage` 키는 `md-blog-2048-best-score` 사용.
4. 다 만든 뒤 스스로 코드를 다시 읽어보며 명백한 문법 오류나 논리 오류(예: 배열 인덱스 실수, 이벤트 리스너 중복 등)가 없는지 점검하세요.
