## 코드

인라인 코드는 `parseMarkdown(raw)`처럼 표시됩니다.

코드 블록:

```js
function greet(name) {
  // 인사말을 만들어 반환한다
  return `안녕하세요, ${name}님!`;
}
```

다른 언어도 강조됩니다:

```python
def greet(name):
    # 인사말을 만들어 반환한다
    return f"안녕하세요, {name}님!"
```
